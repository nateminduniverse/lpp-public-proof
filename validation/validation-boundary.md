# Validation Boundary

Public Proof v2.0 demonstrates a bounded MVP evidence set.

It supports claims about:
- signed Permit issuance
- Permit signature binding
- intent binding
- scope checks
- Permit expiry logic
- authority active/revoked/expired checks
- policy-hash binding
- replay rejection
- ADMIT/DENY paths
- signed Admission Artifact production
- artifact-state hash reconstruction
- artifact chain linkage

It does not support claims of:
- DEFER/COLLAPSE implementation
- independent external reproduction
- production certification
- arbitrary distributed-system replay safety
- universal non-bypassability across all infrastructure
- complete continuous admissibility for long-running distributed actions
- full protocol conformance
