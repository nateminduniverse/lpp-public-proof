# Technical Positioning

LPP is positioned as a Layer 0 constitutional admissibility protocol for AI-triggered execution.

The current Admission Kernel MVP demonstrates a narrower executable subset: authority-bound intent admission, signed Permit issuance, execution-path verification, revocation/replay enforcement, and signed Admission Artifact evidence.

LPP does not replace identity systems, runtime policy engines, capability systems, OAuth/OIDC infrastructure, MCP/A2A transport, SIEM, or post-event logging.

The distinct question is upstream:

> Does this specific AI-triggered action possess sufficient authority-bound legitimacy to become an execution candidate at all?

Public Proof v2.0 does not claim that the underlying cryptographic, authorization, logging, or gating primitives are individually novel.
