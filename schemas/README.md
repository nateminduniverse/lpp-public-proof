# Public MVP Schemas

These five JSON Schema files are **exact copies from the final supplied Admission Kernel MVP package** used for Public Proof v2.0.

They are disclosed as bounded technical contracts for inspection:

- `execution_intent.schema.json`
- `authority_record.schema.json`
- `scope_envelope.schema.json`
- `permit.schema.json`
- `admission_artifact.schema.json`

The source `$id` values are preserved exactly as supplied. They should not be interpreted as canonical public hosting URLs.

Disclosure of these schemas does not disclose the complete runtime implementation or grant unrestricted derivative implementation rights.
